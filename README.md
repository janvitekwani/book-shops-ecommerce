 📚 Book Shops Ecommerce (Backend Only)

This is the backend component of an e-commerce platform for online book shopping. It handles user registration, book catalog, shopping cart, orders, and administrative functionality. Built using Java, Servlets, and JSP.

## ✅ Features

- User registration & login (session-based authentication)
- Book listing and search functionality
- Shopping cart management (add/update/remove items)
- Order processing & confirmation


---

## 🛠 Tech Stack

- **Language:** Java 8+
- **Frameworks/Libraries:** Spring boot 
- **Database:** MySQL
- **Build Tool:** Maven
- **Server:** Apache Tomcat
- **IDE:** IntelliJ IDEA / Eclipse
